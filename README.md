# Platform Control Project

Platform Control Project — это комплексная система автономного управления малогабаритной гусеничной/колёсной платформой Venom Light, предназначенной для выполнения парковых и вспомогательных работ.
Проект объединяет картографию, навигацию, компьютерное зрение, датчики, телеметрию и исполнительные механизмы в единую архитектуру автономного движения.

## 🎯 Цель проекта

Цель — создать надёжную и полностью автономную систему, способную:
	•	безопасно передвигаться по заранее заданным маршрутам,
	•	распознавать дорогу и держаться её контура,
	•	корректно проходить перекрёстки,
	•	выполнять развороты при потере дороги,
	•	останавливаться перед препятствиями,
	•	отображать своё положение и состояние в реальном времени,
	•	управлять навесным оборудованием,
	•	собирать данные для последующего дообучения моделей.

И всё это — с учётом реальных условий эксплуатации: неровности парка, перепады яркости, тени, сложные поверхности, ветки, люди, животные, погодные условия.

## 🧭 Основные компоненты системы

1. Картографический модуль
	•	Использует заранее подготовленные карты (PNG + граф узлов и рёбер).
	•	По клику на карту выбирается старт и цель.
	•	Строится маршрут как последовательность пиксельных точек.
	•	Выделяются перекрёстки (узлы с ≥3 рёбрами).
	•	Контрольные точки автоматически рассчитываются по маршруту.

Задача модуля: дать роботу маршрут, по которому он должен двигаться.


2. Навигационный модуль

Содержит:
	•	прогрессию по маршруту,
	•	расчёт положения робота на карте,
	•	определение направления движения по сегменту маршрута,
	•	оценку расстояния до контрольных точек.

Задача: обеспечивать точное движение вдоль маршрута и корректное переключение сегментов.


3. Модуль лидаров

Использует данные от вращающегося лидара:
	•	определяет наличие препятствий в секторе перед роботом,
	•	вычисляет минимальные расстояния,
	•	инициирует аварийную остановку при опасном сближении.

Цель: предотвратить столкновения.


4. Камера и сегментация дороги (RoadSeg)

Используется нейросеть для выделения дорожной поверхности:
	•	определение контура дороги,
	•	обнаружение её центра,
	•	обнаружение развилок,
	•	оценка «качества дорожности» (road score),
	•	обработка потери дороги.

Результат: робот понимает, где дорога, даже если нет полноценной разметки, и удерживается на ней.


5. Логика движения и стабилизации

На основе маски дороги и маршрута система:
	•	компенсирует смещение робота от центра дороги,
	•	корректирует скорость и направление,
	•	выбирает нужную ветку на развилках (сравнение направления пути и направления сегмента маски),
	•	выполняет разворот при потере дороги.

Цель: плавное и устойчивое движение реалистичного робота по сложному рельефу.


6. Система управления моторами

Реализована через Arduino:
	•	левый мотор — отдельный PWM,
	•	правый мотор — отдельный PWM,
	•	третий канал — вспомогательное оборудование.

Система принимает команды от интерфейса и контроллеров и переводит их в реальные движения робота.

7. Пользовательский интерфейс (UI)

Графический интерфейс:
	•	карта маршрута,
	•	позиция робота,
	•	маска дороги,
	•	лидарная визуализация,
	•	состояние системы (индикаторы),
	•	панель управления,
	•	выбор карты,
	•	запуск/остановка движения.

Цель: дать удобный и понятный инструмент взаимодействия с платформой.

8. Система сбора данных (Dataset Capture)

Во время движения:
	•	фиксируются кадры камеры,
	•	сохраняются снимки лидара,
	•	записываются координаты робота.

Эти данные используются для последующего обучения моделей распознавания дороги и улучшения автономности.

## 🚀 Почему этот проект важен

Платформа Venom Light должна:
	•	работать в реальном парке,
	•	двигаться автономно среди людей,
	•	корректно ориентироваться в среде,
	•	не наезжать на препятствия,
	•	уметь выполнять работу без оператора.

Проект объединяет несколько технологий:
	•	робототехника,
	•	компьютерное зрение,
	•	навигация,
	•	графовые алгоритмы,
	•	машинное обучение,
	•	работа с ROS2,
	•	управление железом,
	•	инженерные решения по безопасности.

В итоге создаётся компактная автономная система, готовая к реальному применению.
